# SLSA Build Requirements

Detailed requirements for producers and build platforms at each Build Track level.

## Producer requirements

Producers (the teams or organizations producing software) must:

- Use a build platform that meets the required SLSA level
- Ensure all build inputs are captured in provenance
- At L3: ensure `externalParameters` in provenance are complete (no undocumented inputs)

## Build platform requirements

The build platform must generate provenance. Three properties determine the level:

### Provenance: exists (L1)

- Platform generates provenance for every build
- Format: SLSA Provenance (`predicateType: https://slsa.dev/provenance/v1`)
- Required fields: `buildType`, `externalParameters`, `builder.id`
- Signature: may be absent or self-signed at L1

### Provenance: authentic (L2)

- Provenance is generated by the trusted control plane, not the build worker
- Provenance is signed using a key the build worker cannot access
- The build platform is "hosted" — not something any user can run locally
- Signature allows consumers to verify provenance came from a trusted platform

### Provenance: unforgeable (L3)

- Strong isolation between build environment and control plane
- Control plane has exclusive access to signing keys (workers cannot steal them)
- Even a malicious build cannot forge provenance for a different source or parameters

### Isolation requirements (L2 for hosted, L3 for isolated)

**Hosted (L2):** Build runs on a platform managed by a dedicated service, not an individual developer's machine.

**Isolated (L3):** Each build runs in an isolated environment such that:

- Builds cannot read or write other builds' state
- Build environments start clean for each build
- Build caches are isolated or have SLSA L3 provenance themselves

## Key provenance fields by level

| Field | Required at | Notes |
| --- | --- | --- |
| `buildType` | L1 | Identifies the build template |
| `externalParameters` | L1 | All untrusted external inputs — MUST be complete at L3 |
| `builder.id` | L1 | Trust anchor URI |
| Signature | L2 | From trusted control plane |
| Isolation | L3 | Environment isolation hardened |
