# OpenBao — Helm Chart Examples

Index of common [OpenBao Helm chart](openbao-k8s-helm.md) configuration examples. Requires **Helm 3.6+**.

## Key Takeaways

- Upstream provides a collection of example configurations for common deployment models (e.g. HA-with-Raft, standalone, auto-unseal variants) — browse them under [openbao.org/docs/platform/k8s/helm/examples](https://openbao.org/docs/platform/k8s/helm/examples/).
- The HA-with-Raft example is the one referenced by the [OpenTofu deployment](openbao-k8s-helm-terraform.md) page.
