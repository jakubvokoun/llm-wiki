# Greg Kroah-Hartman

Linux kernel developer (Linux Foundation Fellow), maintainer of the **stable kernel** releases and many subsystems, and a core member of the **kernel.org [CNA](../concepts/cve-numbering-authority.md) team** that issues all Linux kernel [CVEs](../concepts/cve.md). Author of the _Linux Kernel Monkey Log_ blog (kroah.com).

## Relevant work

- Co-runs the Linux kernel CVE assignment process (one of three core CNA reviewers) and built tooling ([verhaal](https://git.sr.ht/~gregkh/verhaal), commit-tree scripts) for tracking fixes across stable branches.
- Vocal critic of CVSS/NVD severity scoring applied to kernel CVEs, and of CPE for range checking.
- Active on EU [Cyber Resilience Act](../concepts/cyber-resilience-act.md) implications for open source / kernel security.
