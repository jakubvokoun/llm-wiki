# HackTricks

Comprehensive open-source cybersecurity knowledge base and wiki, originally authored by Carlos Polop. Covers offensive and defensive security techniques across Linux, Windows, cloud, containers, web, and more.

## Key Areas

- Linux hardening and privilege escalation
- Container security (Docker, Kubernetes, OCI runtimes)
- Web application security
- Active Directory and Windows attacks
- Cloud security (AWS, GCP, Azure)

## Format

Content is structured as practical, enumeration-first guides — each topic begins with commands and techniques useful for both attackers (CTF, pentest) and defenders (hardening checklists).
