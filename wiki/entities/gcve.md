# GCVE

The **Global CVE Allocation System** — an initiative (driven by CIRCL, Luxembourg) providing a decentralized vulnerability-ID allocation model via **GNAs** (GCVE Numbering Authorities) as an alternative/complement to the central [CVE](../concepts/cve.md) program, plus best-practice documents (BCPs).

## Outputs referenced here

- **GCVE-BCP-02** — [Practical Guide to Vulnerability Handling and Disclosure](../sources/gcve-vulnerability-handling-disclosure.md).
- Related BCPs: ID allocation (BCP-04), GCVE vulnerability/record format (BCP-05), KEV format (BCP-07).
- Tooling: vulnerability-lookup.
