# Trail of Bits

A US-based security research and consulting firm known for offensive/defensive security engineering, cryptography review, and open-source security tooling.

## Testing Handbook

Publishes the **Testing Handbook** ([appsec.guide](https://appsec.guide/)) — a practical, step-by-step guide for developers and security engineers covering [fuzzing](../concepts/fuzzing.md), static analysis (CodeQL, Semgrep), cryptographic testing (Wycheproof, constant-time tooling), and web app security (Burp Suite). Licensed CC BY 4.0.

The fuzzing chapter is the basis for this wiki's [Fuzzing](../concepts/fuzzing.md) and [OSS-Fuzz](oss-fuzz.md) coverage, including guidance on harness writing, [sanitizers](../concepts/sanitizers.md), coverage analysis, and integrating projects into OSS-Fuzz.
